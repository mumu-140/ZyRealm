# P0.3 Live Request State + Manual Interrupt Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add process-local live relay visibility and an authenticated manual-interrupt control that is terminal, health-neutral, request/round-scoped, and safe for downstream WebSocket reuse.

**Architecture:** Each logical HTTP relay request or WebSocket `response.create` round owns one shared `relayControl` with a cause-bearing child context and immutable snapshot API. A process-local registry exposes active snapshots and interrupt-by-ID; attempts share the control pointer and update only safe operational metadata. Existing durable `RelayLog`, failover budgets, health state, and completed-log SSE remain separate.

**Tech Stack:** Go 1.x standard `context`, `sync`, `sync/atomic`, existing Gin router/auth/response helpers, existing relay routing decision model, React 19 + TanStack Query 5 + Next.js 16, Node test runner used by `web/tests/*.test.mjs`.

**Spec:** `docs/plans/2026-09-15-p0.3-live-request-manual-interrupt-design.md`

## Global Constraints

- No database migration.
- No production deployment or container lifecycle operation.
- No local workstation build or test execution; validation evidence must come from GitHub CI or the approved server container path.
- No automatic failover after manual interrupt.
- Manual interrupt must not create provider/credential cooldown, circuit failure, model-suspect state, or outlier evidence.
- Interrupting a WebSocket `response.create` round must not cancel the downstream WebSocket connection context.
- Active state must never expose raw request/response bodies, Authorization headers, API-key secrets, or channel credentials.
- Live request API/types/query keys remain separate from durable `RelayLog` API/types/query keys.
- Single-process registry semantics only; no Redis/distributed cancellation bus in P0.3.
